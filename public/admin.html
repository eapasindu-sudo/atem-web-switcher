    How to set up the camera
    1. Connect the camera to the same Wi-Fi as this PC (camera menu: Network, Wi-Fi, Access Point Set.).
    2. Turn on PC Remote (Network, Cnct./PC Remote, PC Remote Function, PC Remote: On).
    3. Set Access Authen. Settings to On. The user name and password are in Access Authen. Info.
    4. The camera's IP address is shown in Network, Wi-Fi, Wi-Fi Info (or use Find cameras).
    5. ATEM input: the ATEM button this camera is plugged into, so phones show its tally and follow preview.
    6. Network cable instead of Wi-Fi: plug a USB-C to LAN adapter into the camera, connect it to the same router or switch as this PC, and set the camera menu to Wired LAN (Network, Wired LAN, IP Address Setting). Use the wired IP address here. It is steadier than Wi-Fi and gives a smoother live picture.
    7. ATEM Software Control: open its Camera page. CAM 1, CAM 2 … there are the ATEM inputs, so set each Sony camera's ATEM input above. Iris, shutter, gain (ISO), white balance, tint, ND, focus, zoom and record then move the Sony camera, like Middle Control.
    Stream Deck (Bitfocus Companion) and MIDI knobs
    1. In Companion add the Generic: HTTP Requests connection, then make buttons with a GET request to these addresses:
    2. http://this-pc:3000/api/sony/1/rec/toggle REC on camera 1 (start, stop or toggle). Use all instead of 1 for every camera.
    3. /api/sony/1/iris/up, /iris/down, also shutter, iso, nd, kelvin, wbTint, tintAB, tintGM, look, pp.
    4. /api/sony/1/focus/near, /focus/far, /zoom/in, /zoom/out, /af, /preset/2 (recall preset 2), /match (copy camera 1 to all).
    5. /api/sony lists the cameras and whether they are recording.
    6. MIDI knobs: open the CCU page in Chrome or Edge on this PC (http://localhost:3000), tap MIDI, tap a control, then turn a knob or press a key.
